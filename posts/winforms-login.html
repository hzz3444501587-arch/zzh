C# WinForms 登录窗体实现

2026.04.10 · 阅读 5 分钟

在这篇文章中，我将记录如何使用 C# WinForms 实现一个带有错误次数锁定功能的登录窗体。

需求分析

  • 用户名和密码输入
  • 密码输入框使用密码掩码
  • 错误登录 3 次后锁定账户
  • 登录成功后跳转到主窗体

核心代码

private int errorCount = 0;
private const int MAX_ATTEMPTS = 3;

private void btnLogin_Click(object sender, EventArgs e)
{
    string username = txtUsername.Text.Trim();
    string password = txtPassword.Text;

    if (username == "admin" && password == "123456")
    {
        MessageBox.Show("登录成功！", "提示");
        MainForm mainForm = new MainForm();
        mainForm.Show();
        this.Hide();
    }
    else
    {
        errorCount++;
        int remaining = MAX_ATTEMPTS - errorCount;
        if (remaining > 0)
            MessageBox.Show("密码错误！剩余 " + remaining + " 次", "警告");
        else
        {
            MessageBox.Show("账户已锁定！", "错误");
            btnLogin.Enabled = false;
        }
    }
}

界面设计要点

  • 设置 PasswordChar 为 * 隐藏密码
  • 设置 AcceptButton 为登录按钮，支持回车登录
  • 设置 FormBorderStyle 为 FixedDialog
  • 设置 StartPosition 为 CenterScreen
小心处理窗体生命周期——用 Hide() 而不是 Close()。
