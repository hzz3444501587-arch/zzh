数据库范式与 SQL 优化笔记

2026.04.02 · 阅读 6 分钟

数据库设计是后端开发的基础。这篇是课堂笔记整理。

三大范式

第一范式 (1NF)：原子性

每个字段的值必须是不可再分的原子值。

第二范式 (2NF)：消除部分依赖

非主键字段必须完全依赖于整个主键。

第三范式 (3NF)：消除传递依赖

非主键字段之间不能存在传递依赖关系。

SQL 优化技巧

1. 合理使用索引

CREATE INDEX idx_student_name ON students(name);
CREATE INDEX idx_stu_dept ON students(department_id, grade);

2. 避免 SELECT *

SELECT name, grade FROM students WHERE grade > 90;

3. 使用 EXPLAIN 分析

EXPLAIN SELECT name FROM students WHERE department_id = 3;
先把范式搞清楚，再去谈优化。基础不牢，地动山摇。
